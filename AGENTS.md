# EGE Written Exam UI

For every written EGE task numbered 1–38, use the implementation in
[ege-written-exam-ui](ege-written-exam-ui/SOURCES.md) and the
[ege-written-exam-ui skill](.agents/skills/ege-written-exam-ui/SKILL.md).
Use the template for the exam number. Supply the complete prompt, unchanged
passages, answer choices, chart or table, and the activity's existing controls.

EGE Teachers Hub is the design authority. Its lesson and homework diagnostics
define the opening instructions, typography, spacing, proportions, controls,
and order of working panels. Keep passages continuous. Keep task 37 and both
versions of 38 in two panels with the complete prompt on the left and the
full-height editor on the right. In task 38 keep all five points of the plan.
Keep one heading per task. Preserve readable font sizes and existing scoring,
timers, audio, storage, navigation, and submission.

Verify changes in the browser at the same viewport as the reference. Exercise
the normal entry point and save or check answers before publishing. Exercise
submission with a local test endpoint to avoid adding a test record to the
teacher's results.
